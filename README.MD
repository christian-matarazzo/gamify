# 🎮 Gamify — Digital Game Keys Reselling Platform
> A full-stack e-commerce platform for buying and reselling digital game license keys, inspired by Instant-Gaming. Built as a group project during the Boolean Web Development course.

## Overview
Gamify is a client-side e-commerce web application focused entirely on the end-user shopping experience. Users can browse, search, and purchase digital license keys for video games.
The platform is fully responsive, never performs full page refreshes, and keeps the product ID unexposed at all times.

## Features

### ✅ Core Milestones

| Feature | Description |
|---|---|
| **Homepage** | Hero section + three product sections |
| **Search Page** | Search bar with sorting options (price, name, newest, oldest) and result display |
| **Product Detail** | Full product info with add-to-cart functionality |
| **Cart** | Quantity management and total price display |
| **Checkout** | Billing/shipping form with order summary |
| **Order Emails** | Confirmation email sent to both customer and seller |
| **Free Shipping** | Automatically applied when the order exceeds a minimum spend threshold |
| **Discount Codes** | Promo code input at checkout with validity period (from/to date) |
| **Wishlist** | Add/remove products from a dedicated wishlist page |
| **Related Products** | Suggested products shown on the product detail page |
| **Welcome Popup** | First-visit popup that collects the visitor's email and sends a thank-you email |
| **Quantity Management** | Shows stock availability, blocks adding out-of-stock items, prevents checkout if a cart item goes out of stock |
